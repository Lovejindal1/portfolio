## 💻 How to Run Locally

You can open the portfolio in two simple ways:

### Option 1: Direct File Open
Double click `index.html` in your file explorer (`E:\portfolio\index.html`) to open directly in any modern browser.

### Option 2: Local HTTP Server (Recommended)
Open a terminal in `E:\portfolio` and run:

```bash
# Using Python
python -m http.server 4173

# Or using Node.js npx serve
npx serve .
```
Then visit: `http://localhost:4173`

## 🌐 Deploy to GitHub Pages or Vercel (1-Click)

### GitHub Pages:
1. Create a repository named `portfolio` on your GitHub account (`https://github.com/Lovejindal1/portfolio`).
2. Run in `E:\portfolio`:
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of cyber portfolio"
   git branch -M main
   git remote add origin https://github.com/Lovejindal1/portfolio.git
   git push -u origin main
   ```
3. In repository Settings > **Pages**, set source to `main` branch `/ (root)` and click Save.

### Vercel:
Run `npx vercel` in `E:\portfolio` and follow the prompts.
